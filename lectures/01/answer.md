# 第1回 解答

## 演習

- 講座に固有の質問（宿題の3レベル）へのモデルの回答（要約でよい）：gemini-3.5-flash-lite は、AIE2026 を「AIエンジニア育成講座2026年版など」と推測したうえで、「レベル1（基礎・入門）／レベル2（標準・応用）／レベル3（発展・挑戦）」という難易度別の3段階だと答えた。「全員レベル2まで必須」「レベル3はボーナス課題」のようなルールが多いとも書き、最後に講座の資料や講師に確認するよう勧めていた。
- 用語集の正しい意味と比べて気づいたこと：用語集（homework-levels）では「基礎（講義内容の確認）・実装（自分でコードを書く）・発展（調査や試行）の3段階で、どれか1つに取り組めば完了。原則として採点はしない」。「基礎」「発展」という言葉と難易度順という大枠は近いが、2段目は「実装」ではなく「標準・応用」で、「レベル2まで必須」という事実と違うルールを一般論の形でもっともらしく付け足していた。講座に固有のことは学習データに無いので、それらしい一般論で埋めてしまう（ハルシネーション）ことを確認できた。
- 表示できたトークン数（入力 / 出力）：「LoRAとは何ですか？」が 7 / 632、「AIE2026の講座の宿題にある「3レベル」とは何ですか？」が 21 / 518（どちらも gemini-3.5-flash-lite）。app/ask.py の TODO の場所で、response.usage_metadata の prompt_token_count と candidates_token_count を表示するようにした。

## 宿題

- 取り組んだレベル：基礎
- やったこと：講座に固有の質問「AIE2026の講座の宿題にある「3レベル」とは何ですか？」（ask.py の既定の質問）を、AIE_MODEL を切り替えて gemini-3.5-flash-lite と gemini-3.8-flash でそれぞれ3回ずつ実行し、回答の内容とトークン数を比べた。temperature は既定のまま変えていない。
- 結果：

| モデル | 回 | 出力トークン | 3段階の名前（モデルの回答） | 特徴 |
|---|---|---|---|---|
| gemini-3.5-flash-lite | 1 | 525 | 基礎・入門編／応用・実践編／発展・挑戦編 | 「AIエンジニア育成講座などを指していると推測」と前置き。「全員レベル3まで必須の場合も、どれか1つを出す場合もある」 |
| gemini-3.5-flash-lite | 2 | 793 | 3つのパターン（難易度別／AI活用度別／Bloomのタクソノミー） | 「シラバスは直接参照できない」と書き、候補を並べた |
| gemini-3.5-flash-lite | 3 | 675 | 3つのパターン（思考の深さ／難易度・選択式／AI活用の習熟度） | 「Level 1 は全員必須の基本課題」 |
| gemini-3.8-flash | 1 | 674 | 基礎・必修／応用・推奨／発展・挑戦 | CNN や Kaggle など機械学習講座寄りの具体例。「ほとんどです」と言い切りに近い |
| gemini-3.8-flash | 2 | 613 | 基礎・必修／応用・推奨／発展・挑戦（松竹梅） | Dify や Zapier 連携などの例。「まずはレベル1の提出だけで問題ない」 |
| gemini-3.8-flash | 3 | 710 | 基礎・必須／応用・標準／発展・挑戦 | Must / Should / Nice-to-have。生成AIの講座なら別の3レベルもありうると補足 |

  - 入力トークンはどの回も 21 で同じだった。
  - gemini-3.8-flash は5回呼んで2回が「モデルが混み合っています（503）」で失敗した。成功した回も応答に1〜1.5分ほどかかった（time で 1m29s、1m6s）。flash-lite は毎回10秒以内に返った。
  - 6回とも正解（基礎・実装・発展の3段階で、どれか1つで完了）にはならなかった。

- 気づき・疑問：
  - flash-lite は回ごとに答えの形そのものが変わり（1つの案を示す回と、3つのパターンを並べる回があった）、ぶれが大きかった。一方で「シラバスは参照できない」など、知らないことを認める書き方が多かった。
  - gemini-3.8-flash は3回とも「基礎／応用／発展・挑戦」というほぼ同じ骨組みで、答えは安定していた。ただし具体例や修了条件をより自信を持って書くので、間違っていても正しそうに見える。上位モデルにしても講座固有のことは知らないままで、ぶれが減るぶん誤りに気づきにくくなると感じた。
  - 「基礎」「発展」は当たっていたが、真ん中の「実装」はどちらのモデルも当てられなかった。講座固有の正解は、第3回のように用語集を検索できるツールを持たせないと得られないと思う。
  - 疑問：gemini-3.8-flash の応答が遅いのは、思考（thinking）に時間やトークンを使っているからなのか。usage_metadata の thoughts_token_count も表示すれば確かめられそう。
